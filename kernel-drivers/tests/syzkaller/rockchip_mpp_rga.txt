# Draft syzlang for the RK3588 MPP/RGA compatibility rewrite ABI.
#
# This intentionally starts with the current librockchip_mpp/librga-visible
# surface rather than the full BSP history. Hardware-submitting calls are marked
# disabled/no_generate so the draft can be used first for parser/lifetime
# hardening and then selectively enabled on an IOMMU-contained fuzzing board.
#
# The "# ABI:" lines are checked by check-rockchip-syzlang.sh against
# kernel-drivers/tests/abi-probe.sh.
